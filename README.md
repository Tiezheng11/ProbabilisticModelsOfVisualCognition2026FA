# Probabilistic Models of the Visual Cortex — Fall 2026

Course website for AS.050.375/675 and EN.601.485/685 at Johns Hopkins University.

## Preview locally

From this directory, run:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Publish with GitHub Pages

Push this directory to the Fall 2026 course repository, then enable GitHub Pages from the repository's default branch and root directory in **Settings → Pages**.

Lecture materials can be added under `slides/`. The Fall 2026 Gradescope entry code is `YG77VP`.
